# CV限定難例のTransformer初期化に対する再現性

[前回](../phoneme-cv-hard-negatives/README.md)はTransformer seedが1個で、CV限定16kの等コーパス平均EERが1.799→1.599%へ改善したが、64k選定モデルは改善が弱かった。今回は初期化・dropoutの乱数への依存を切り分ける。学習データ・順序・負例候補のサンプリングは固定し、話者母集団を増やした独立検証とは扱わない。

## 事前固定する条件

- 420話者の既存入力、216k固定encoder、音響seed 20260926 / 20260927 / 20260928。
- Transformerの新規seed 20261016 / 20261017。既存20261015は監査済み参照として別掲する。新規6組と既存3組を混ぜて再現性を主張しない。
- 各組でランダム負例とCV限定難例を比較。新規学習12本。以前の学習ペア・並びをそのまま再利用する。
- 新しいseedごとにランダム負例の共通4kを学習し、同じmodel・optimizer・RNGから両条件へ分岐。4k以前の学習率は元のcosine、以後は元と同じ3e-5。
- 16k/64k予算、500更新ごとの3コーパス平均validation EER最小・最初の同値を主結果の選定規則として維持。更新0も候補。固定最終checkpointは副結果。
- 72モデル（新規48、既存24）を固定し、全216 validation閾値を固定してから新規test推論。新規モデルは独立再推論で全スコアを検算。既存モデルのスコアは前回のhash検証済み成果物を再利用し、指標の完全一致も確認する。
- 新規6組の対応差、Transformer seed別平均、音響seed別結果、JVS/CV/JTube、等コーパス平均、FAR/FRR、採点率を報告する。すべて既観測testであり、testに応じてseed・予算・選定規則を変更しない。

改善が再現するかに加え、選定モデルと最終モデルで16k→64kの方向が変わるかを確認する。新規6組も同じ評価話者を再利用しており、6つの独立した母集団や信頼区間とは扱わない。今回は初期化とdropoutを同時に変えるため、両者の効果を分離しない。学習順のseedは変えない。

利用者の「CVの母音区間の質が悪いのでは」という仮説は未検証で保持する。今回の改善が再現しない場合は既存区間の品質と識別誤りの関係を次の切り分け候補にする。再現しても品質仮説が否定されたことにはならない。新しい録音・データ追加は行わない。

## 実行

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  poc/phoneme-verification-evaluation/.venv/bin/python \
  poc/phoneme-cv-seed-replication/replication.py execute
```

既存コード・入力を変更せず、`artifacts/phoneme-cv-seed-replication/init420-20261012-v1`へ保存する。6 worker、各CPU 1 thread。prefix終了前の異常停止では、旧trainerの非原子的なbest保存を誤って再開しないよう停止する。その場合は途中成果物を残し、別runを事前固定してやり直す。完了prefixと4k以後の継続checkpointは再利用・再開できる。

学習前に短い実学習で、seedを変えると重みが変わること、学習scheduleが固定であること、同じprefix・scheduleから分岐すれば両条件が完全一致することを確認する。継続学習は既存のresume検証済みworkerを利用する。

2026-10-12 19:22 JSTに開始し、20:54〜20:55に全学習、21:06に評価・監査が完了。短い実学習による統合テスト（初期化変更、schedule固定、共通prefix、同一scheduleでの両分岐の最終重み/RNG一致、完了prefixの再利用）とRuff check / format checkは成功。異常停止・途中再開はなかった。

## 結果

**CV限定の難例選択によるCV改善は、新しいTransformer seedでも再現した。** 新規6組の16k選定では5組改善・1組同値、64k選定では6組すべて改善した。ただしJTubeの平均EERは少し悪化しており、全コーパスの一様な改善や運用条件の達成とは判断しない。

主結果は3コーパス平均validation EERで選んだモデル。次表は新しいTransformer 2 seeds × 音響3 seedsの6組だけの平均test EERであり、前回のseedは含めない。低いほど良い。各データに別々のモデルを選ぶのではなく、組ごとに共通の選定モデルを使う。

| 予算 | 評価データ | ランダム負例 | CV限定難例 | 対応差 | 改善 / 同値 / 悪化 |
| ---: | --- | ---: | ---: | ---: | --- |
| 16k | JVS | 1.403% | 1.158% | −0.245 pp | 5 / 1 / 0 |
| 16k | Common Voice | 3.721% | 3.349% | −0.372 pp | 5 / 1 / 0 |
| 16k | JTube | 0.997% | 1.058% | +0.061 pp | 2 / 2 / 2 |
| 16k | 等コーパス平均 | 2.040% | 1.855% | −0.185 pp | 5 / 1 / 0 |
| 64k | JVS | 1.273% | 1.199% | −0.075 pp | 4 / 0 / 2 |
| 64k | Common Voice | 3.617% | **3.052%** | **−0.566 pp** | **6 / 0 / 0** |
| 64k | JTube | 0.990% | 1.026% | +0.037 pp | 1 / 3 / 2 |
| 64k | 等コーパス平均 | 1.960% | **1.759%** | **−0.201 pp** | **6 / 0 / 0** |

CVの64k選定における相対EER低下は15.6%。16kで全コーパス同値だった音響seed 20260926 / Transformer seed 20261017は、両条件とも介入前の3kモデルを選定していた。これを難例学習の改善として数えない。64kでは全6組が介入後のモデルを選んでいる。

### Transformer seed別の再現性

各セルは同じ音響3 seeds平均。旧seedを新しい再現確認と区別する。

| Transformer seed | 区分 | CV 16k選定（ランダム→CV限定） | CV 64k選定（ランダム→CV限定） | 等コーパス16k選定 | 等コーパス64k選定 |
| ---: | --- | --- | --- | --- | --- |
| 20261015 | 既観測参照 | 3.152→2.835% | 3.298→3.148% | 1.799→1.599% | 1.839→1.822% |
| 20261016 | 新規 | 3.666→3.428% | 3.688→3.161% | 2.028→1.815% | 1.932→1.771% |
| 20261017 | 新規 | 3.777→3.270% | 3.547→2.942% | 2.052→1.895% | 1.988→1.746% |

両方の新seedでCV・等コーパス平均の改善方向は一致した。一方、前回の16k CV限定2.835%という絶対値までは再現せず、初期化による水準差は残る。「負例選択による対応差」と「特定seedの絶対EER」を区別する。

### 学習量とcheckpoint選定

CV限定の新規6組平均は、16k→64kの選定モデルでCV 3.349→3.052%、等コーパス平均1.855→1.759%へ改善した。ただし6組中3組改善・1組悪化・2組同値であり、全組でスケールしたわけではない。同値2組は64k予算でも14k / 6.5kモデルを選んでおり、追加更新のモデルを使っていない。旧seedでは3組すべて悪化したので、「長くすれば必ず良い」「長くしても改善しない」のどちらも支持しない。

| 固定最終checkpoint（副結果） | ランダムCV | CV限定CV | ランダム等コーパス平均 | CV限定等コーパス平均 |
| --- | ---: | ---: | ---: | ---: |
| 16k | 3.836% | 2.781% | 2.149% | 1.797% |
| 64k | 3.478% | 2.678% | 2.104% | 1.789% |

固定最終モデルでも両予算のCVと等コーパス平均は、ランダムに対して新規6組すべて改善した。ただしCV限定の16k→64k最終モデルはCVで4組改善・2組悪化。等コーパス平均も4組改善・2組悪化で、平均の追加改善は−0.008 ppにとどまる。新seed 20261017では等コーパス平均が1.777→1.835%へ悪化している。testを見て最終モデルへ主結果を切り替えない。

## 固定閾値の性能と限界

validationでFAR1%を目標に固定した閾値をtestに適用した、新規6組のCV平均。FAR/FRRは未採点を拒否として含む。EERは採点可能な照合のみの指標。

| CV条件 | ランダム FAR / FRR | CV限定 FAR / FRR | CV限定でtest FAR>1%の組数 |
| --- | --- | --- | ---: |
| 16k選定 | 0.656% / 45.407% | 0.707% / 43.593% | 1/6 |
| 64k選定 | 0.708% / 45.556% | 0.879% / 41.759% | 2/6 |
| 16k最終 | 0.688% / 45.407% | 1.043% / 39.130% | 4/6 |
| 64k最終 | 0.835% / 44.019% | 1.166% / 38.593% | 3/6 |

FRRの低下とFARの上昇が併存している。JTubeの64k選定は平均FARが1.110→0.961%に下がる一方、平均FRRは40.556→40.694%へ上がった。平均FARが1%未満でも全組で目標を達成したわけではない。採点率は全条件共通でJVS 98.000%、CV 64.556%、JTube 59.833%。今回の変更では未採点率は変わらない。

負例選択の改善を、別の話者集団・新しい録音・新しい学習順で確認したわけではない。今回の6組は固定された同じ入力と評価話者を再利用する。母集団への汎化・信頼区間・根本原因の証明として扱わない。モデルの標準設定・本番閾値は変更していない。

## 母音区間の品質仮説について

「何も改善しない」という結果ではなく、データを変えずに負例選択だけでも改善が再現した。ただし、これは元の母音区間の品質が十分である証拠ではない。品質と学習方法の両方が影響している可能性は残る。

区間の切り出し誤差、長さ、クリッピング、音量、有声性などの代理指標を、残る誤照合やスコア変化と対応させる調査は実施可能。録音品質・区間境界・前処理を分けて扱い、音量を雑音量とみなさない。聴感と境界の妥当性は、抽出例をレビューUIに並べて利用者の確認と組み合わせられる。相関を見つけただけでは因果は確定しない。

次の品質調査をする場合は、まず既存の評価音声で問題が残る層を探索する。品質基準や除外閾値を既観測testのEERに合わせて最適化せず、入力を変更しない診断から始める。学習母音の品質が原因という仮説の確認には、学習側の品質分析と、品質による選別を介入とする別の固定比較も必要。この品質調査自体は未実施。
