# 学習データの品質項目

## 1. 目的

本書では、モデルの認証性能に影響すると考えられる学習データの品質項目と、
データセット構築時に記録・集計する内容を定義する。品質項目と認証性能の因果関係は
この段階では確定せず、Phase 3以降の学習曲線と条件別評価で検証する。

## 2. 品質の考え方

本PoCにおけるデータ品質は、音声がきれいであることだけを意味しない。未知話者かつ
異なる収録条件へ一般化できるモデルを学習し、公平に評価できるデータ構成であることを
含む。

特に、次の三つを区別する。

- **利用可能性**: 波形、音素ラベル、時間区間から学習入力を機械的に構成できるか
- **学習上の品質**: 話者差と話者内変動を学ぶための量、多様性、均衡があるか
- **評価上の品質**: 学習・登録・照合間のリークを防ぎ、未知条件で評価できるか

区間品質の指標やレビュー結果は分析用属性として保持し、レビュー済みの個別区間だけを
除外、重み付け、優先サンプリングするためには使用しない。系統的な問題が層化レビューで
確認された場合は、個別判断ではなく再現可能な一律の生成・採用規則を全区間へ適用する。
区間が生成されない、時刻が不正、音声を読み出せないなど、学習入力を構成できない
機械的な失敗は使用対象外とし、理由と件数を記録する。

## 3. モデル精度に影響する品質項目

### 3.1 話者の量と多様性

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 話者数 | 分割別のユニーク話者数 | 学習話者が少ないと、未知話者へ一般化する話者特徴を学びにくい |
| 話者ごとのデータ量 | 発話数、総時間、母音区間数 | 少数話者や一部話者への過適合、話者間の寄与の偏りにつながる |
| 声質の多様性 | コーパスが提供する属性と収録元の構成 | 学習時に現れない声質に対する性能が不安定になる可能性がある |
| 話者間の量的均衡 | 話者別の発話数、時間、区間数の分布 | データ量の多い話者が損失を支配する可能性がある |

声質や話者属性は、コーパスが明示的に提供し利用条件上扱える情報だけを記録する。
音声から年齢、性別などの属性を推定して補完しない。

### 3.2 同一話者内の変動

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 収録セッション数 | 話者別のセッション数 | 単一セッションだけでは、日や収録状態の変化を話者内変動として学べない |
| 収録条件 | マイク、環境、収録日、距離など利用可能なメタデータ | 話者と機器・環境が固定的に対応すると、環境を話者特徴として学ぶ可能性がある |
| 発話条件 | 発話速度、音量、発話長など取得または算出できる値 | 同一話者の自然な発話変動への頑健性に影響する |
| 発話内容の多様性 | 発話文ID、同一文・異なる文の件数 | 特定の文章や前後音素を話者識別の手掛かりにする可能性がある |

### 3.3 母音区間の量と均衡

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 母音別区間数 | `/a/ /i/ /u/ /e/ /o/`別の区間数 | 母音間の偏りが、母音別encoderや統合スコアの性能差につながる |
| 話者×母音の区間数 | 各話者・各母音の区間数 | 同じ母音について正例と負例を構成できるかを左右する |
| 話者×母音×セッションの区間数 | セッションを分けた区間数 | 別セッション間の正例を構成できるかを左右する |
| 区間長 | 母音別、話者別の分布と分位点 | 短い区間では話者情報が不足し、長さの偏りを手掛かりにする可能性がある |
| 長母音・連続母音 | `is_long`、`expected_units`と区間数 | 母音ごとの長さや表現粒度の偏りに影響する |
| 無声化母音 | `is_devoiced`または無声化候補と区間数 | とくに`/i/`と`/u/`で有声区間と異なる情報量になる可能性がある |

区間総数だけで規模を判断しない。同じ録音から得た多数の区間は収録条件を共有するため、
独立した話者やセッションを増やすことの代わりにはならない。

### 3.4 アライメントと信号の状態

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 音素列の整合性 | 期待音素列との一致、不一致理由 | 誤った音素ラベルは、同じ母音という学習条件を崩す |
| 時間区間の妥当性 | 開始・終了時刻、元音声範囲との整合性 | 不正な区間は学習入力を構成できない |
| 信号レベル | RMSなどの信号統計と低レベルフラグ | ほぼ無音の区間では十分な話者情報を取得できない可能性がある |
| クリッピング・無音 | 検出件数と話者・収録条件別の分布 | 特定話者だけに偏ると、録音異常を話者特徴として学ぶ可能性がある |
| 区間品質フラグ | 短区間、低レベル、Phase 1レビュー属性 | アライナーの失敗傾向と認証性能の関係を後から分析するために必要となる |
| 前後音素 | 対象母音の直前・直後の音素 | 共調音や子音遷移が話者表現へ与える影響を分析するために必要となる |

品質フラグだけを事前検証なしに不採用理由にはしない。Phase 2の層化レビューでは
`near_silent`の系統的な利用困難が確認されたため、このフラグは個別レビューによらない
一律の規則としてPhase 3入力へ反映する。採用規則を変更した場合も、元の品質属性と件数を
保持し、固定した評価条件で影響を追跡できるようにする。

### 3.5 独立性とデータリーク

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 話者の分離 | train、validation、test間の話者ID重複 | 重複すると未知話者への一般化性能を評価できない |
| 元録音の分離 | 元ファイルIDとチェックサムの分割間重複 | 同じ録音環境や波形の共有によって性能を過大評価する |
| セッションの分離 | 評価話者の登録用・照合用セッション | 同一セッションだけの照合では、収録条件の一致に依存する可能性がある |
| 派生データの由来 | 元音声、アライメント、抽出設定、生成物の対応 | 同じ元データの別名ファイルや再生成物によるリークを検出する |
| 分割決定の時点 | 分割規則、乱数seed、設定バージョン | 評価結果を見た後の分割変更による選択バイアスを防ぐ |

### 3.6 学習ペアと評価試行の成立性

| 品質項目 | 記録・集計する内容 | 想定する影響 |
| --- | --- | --- |
| 正例候補 | 同一話者・同一母音の区間組数、別セッション組数 | 正例が不足すると話者内変動を学べない |
| 負例候補 | 同一母音を持つ異なる話者の数と区間組数 | 負例の多様性が不足すると話者間の識別を学べない |
| 登録データ | 評価話者・母音別の登録可能区間数 | プロファイルの安定性と登録条件の比較可能性に影響する |
| 照合データ | 評価話者・母音別の照合可能区間数 | genuine試行の数と条件別評価の安定性に影響する |
| 評価試行 | genuine、impostorの試行数と話者組の分布 | FAR、FRR、EERの推定精度と話者偏りに影響する |

## 4. 記録単位

品質項目は、値の性質に応じて次の単位で保持する。

- **コーパス単位**: コーパス名、版、ライセンス、取得方法、全体の収録設計
- **話者単位**: 話者ID、所属する分割、発話数、セッション数、総時間
- **セッション単位**: セッションID、収録条件、収録日など提供されるメタデータ
- **発話単位**: 元音声、発話文、音声仕様、長さ、チェックサム、生成設定
- **母音区間単位**: 母音、境界、長さ、信号統計、前後音素、品質フラグ
- **データセット集計**: 分割・話者・母音・セッションごとの分布、失敗件数

同じ情報を複数の場所へ手入力せず、manifestから集計結果を再生成できる構成にする。

## 5. Phase 3以降での検証

各品質項目が実際に認証性能へ与える影響は、同一の評価セットを固定し、次のような
学習曲線と条件別評価で確認する。

- 学習話者数を変えた比較
- 1話者・1母音あたりの区間数を変えた比較
- 単一セッションと複数セッションを使った比較
- 母音別の認証性能比較
- 登録区間数を変えた比較
- 区間長、無声化、品質フラグ、収録条件別の性能集計

品質属性を記録する目的は、都合のよいサンプルだけを選ぶことではなく、性能の変化を
説明し、次に増やすべきデータを判断できるようにすることである。
