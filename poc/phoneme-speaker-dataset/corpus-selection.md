# コーパスの選定

## 1. 決定

Phase 2の音素別話者データセットには、JVS corpusを採用する。

- 決定日: 2026-09-26
- 対象フェーズ: Phase 2から開始する初期PoC
- 採用アライナー: Julius

## 2. 採用理由

- 日本語の複数話者による音声と発話情報が整理されている。
- Phase 1ですでにJVS由来音声を使用しており、Juliusによる処理手順と実績がある。
- 話者IDと発話の対応が提供され、話者単位の学習・検証・評価分割を構成できる。
- YouTubeなどから音声を新規収集する場合に必要な話者同定、文字起こし、重複除去、
  利用条件確認などの作業を避け、音素方式の成立性検証へ工数を集中できる。

## 3. この決定の位置づけ

JVSの採用は、統制されたデータで音素ベースの話者表現を学習できるかを確認するための
PoC上の決定である。JVSだけで、別日、別端末、異なる環境を含む実利用条件での認証性能を
保証するものではない。

PoCで有望な結果が得られた場合は、別セッションや異なる収録条件を持つデータによる
追加評価と、より多くの学習話者を含むデータへの拡張を検討する。

JVSで低性能だった場合も、その結果だけではプロジェクトを終了しない。学習データ上の
性能、未知話者性能、話者数に対する学習曲線から、方式の問題とデータ規模不足を区別する。
段階ごとの判定と実環境データへの移行条件は、[段階的な検証戦略](validation-strategy.md)で
定義する。

## 4. 未決事項

- JVS内で利用する発話セットと発話スタイル
- 使用する話者と発話の採用規則
- train、validation、testの話者数と固定分割
- 登録用音声と照合用音声の分離方法
- JVSが提供する収録・話者メタデータの利用範囲
- データ取得、ライセンス表示、チェックサムの記録方法
