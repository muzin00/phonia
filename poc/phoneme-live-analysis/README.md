# 同日実録音の登録量・音素別診断

実録音パイロットの登録20録音と照合用試行を使い、追加の収録なしで登録負担とスコアの構成を点検する。1人・同日・同マイクの既観測データによる探索である。認証閾値を決めず、FAR/FRRを算出せず、機器原因の調査は行わない。

比較は登録の先頭5・10・15・20録音を固定し、録音の選別・並べ替え・照合スコアによる選択を行わない。各条件には指定文5種がそれぞれ1〜4回含まれる。既存と同じ音源分散・音素ごと最大30区間の選択を行い、各母音最低10区間を満たさない条件は登録不成立とする。

各条件で利用可能な全音素によるスコアに加え、成立条件間で共通する登録音素だけを使った比較を行う。登録量を減らすと音素集合も変わりうるため、両者を混同しない。どちらも照合側に5母音を要求し、未完了・中断・音声なしを結果から削除しない。練習音声は登録にも照合にも流用しない。

元の20録音プロフィールを基準に、母音ベクトルのコサイン類似度、4件の採点可能な照合スコアの差を確認する。1人の4スコアなので信頼区間・一般化性能は推定しない。「スコアが高い」だけでは登録条件を採用しない。

20録音条件では音素別スコアと区間数を一覧化し、1音素を外した場合のスコア変化も診断する。これは平均値への寄与を知るためであり、低スコアの音素を本番から除外する選択には使用しない。他人との識別力は未評価である。

入力episode、派生ファイル、保存済みプロフィール、以前の照合結果、解析コードを固定してから計算する。元の録音サーバーの実装・固定条件・保存プロフィールは変更しない。

```sh
OMP_NUM_THREADS=1 poc/phoneme-alignment-evaluation/.venv/bin/python -m unittest discover -s poc/phoneme-live-analysis/tests -v
OMP_NUM_THREADS=1 poc/phoneme-alignment-evaluation/.venv/bin/python poc/phoneme-live-analysis/diagnose.py
```
