# 第三コーパス追加の事前確認

2026-10-11。**JTubeSpeech-ASVの日本語音声を取得し、自動書き起こしから既存の音素抽出につなぐ経路を確認した。追加学習と改善傾向の比較はまだ実施していない。**

## 入力の固定

公式ver1.1配布ZIPは8,850,333,946 bytes。ZIP目次は212,137エントリーで、READMEと4つのリストを取得した。日本語限定リストの46,542発話は979ラベルに属し、そのうち50発話以上ある184ラベルから180ラベルを選択した。公式testに現れる92ラベルとのID重複は0件。これらはラベルの照合であり、JVS・Common Voiceを含む実在人物の重複を検査したものではない。

分割はtrain 140・validation 20・test 20、各50発話で9,000発話。固定seedで話者と発話を選び、`selection-freeze.json`を新規音声の処理前に保存した。学習追加70ラベルの条件はtrain 140ラベルの先頭70を使う。採点結果に合わせた入れ替えはしない。

## trainだけの少量確認

固定trainの先頭3ラベルから各4発話、計12発話を使用した。

| 項目 | 結果 |
| --- | ---: |
| 音声合計 | 56.592秒 |
| ローカルASR処理合計 | 15.729秒（モデル取得時間は含まない） |
| 音素抽出で処理できた発話 | 12/12 |
| QC後の採用音素候補 | 499区間・28種類 |
| 採用母音区間 a / i / u / e / o | 71 / 57 / 42 / 39 / 60 |
| 単発で5母音がそろう発話 | 6/12 |
| ASRの区間平均log probabilityが−1未満の区間を含む発話 | 1/12 |

ASRはMLXの`whisper-large-v3-turbo`を固定revisionで使用し、language=ja、temperature=0、前の発話文脈を使わない設定とした。モデル・manifest・処理コード・ライブラリ版を`pilot-asr/freeze.json`へ保存した。1件目の初期化を除いたASR処理中央値は約1.142秒/発話。この小標本から9,000件へ単純外挿すると書き起こしだけで約2.9時間となるが、全体の発話長や再試行を含む完了時間の保証ではない。

機械生成テキストには語の取り違えの可能性があり、低いASR信頼度の短い発話もあった。外国語の発音例を含む教育音声を日本語の文字列へ写している可能性もある。日本語subset指定、アライメント成功、音量条件通過のいずれもラベル正解の証拠にはならない。今回の信頼度の値は診断であり、学習入力をそれだけで採否判定する基準としてはまだ採用していない。

初回の抽出試行は、配布側の大文字IDが既存処理のID形式に合わず12件とも失敗した。元ラベルを保持し、処理用話者IDを小文字、発話IDを元音声SHA-256由来のIDに対応させて同じ12件を再実行した。失敗記録は`pilot-quality-id-format-attempt.json`に残している。音声の差し替えはしていない。

## 保存先と検査

run: `artifacts/phoneme-corpus-scaling/jtube-20261011-v1/`。

- `selection-freeze.json`: 取得前の分割と全対象発話。
- `pilot-download.json`: 固定した12件の取得元・CRC・SHA-256。
- `pilot-asr.json` / `pilot-asr/`: 機械生成テキストとモデル・設定の固定情報。
- `pilot-quality.json` / `pilot-extraction/`: 発話別の抽出結果とQC。
- `download.json`: 全9,000発話の取得が正常完了した場合にだけ生成される全件manifest。

CRC不一致、Range要求への全体応答、正常な部分取得と保存hashの3テストが成功。Ruff check / format check、git diff --checkも確認した。取得と機械的な抽出の経路を確認した段階で、人手の音素ラベル評価や新モデルの認証性能評価を実施したという意味ではない。

## 次の判定

取得後、機械生成テキストを含む学習入力の品質規則と、音素支持数・発話量を揃える比較条件を固定する。[比較設計案](README.md)の同数コーパス変更と140→210→280ラベルの拡大を分け、JVS・Common Voice・第三コーパスそれぞれで改善と悪化を示す。現行140ラベルのモデルや本人の登録プロフィールは変更しない。本人の追加録音をこの作業の前提にしない。
