# 音素選別の結果と判断

**`/k/` と `/ch/` を除いた34音素でtest平均EERは1.495→1.421%へ下がったが、確認用話者の平均では改善せず、標準設定への置換は見送る。**

最新SRC490のencoderとTransformerを固定し、3音響seedに共通する音素集合を探索した。
全36から1音素の追加・削除、保持音素と除外音素の1対1入れ替えを比較し、140通りを評価した。
`k`、続いて`ch`を除く2回の変更が採用され、それ以上の追加・削除・入れ替えでは探索EERが改善しなかった。
操作回数の上限に達して止まったわけではない。ただし、複数音素を同時に変える全組み合わせは網羅していない。

## testで観測した差

3音響seed平均、同じ発話・同じ本人/他人試行・同じ採点率での比較。

| コーパス | 全36 EER | 選別後 EER | 対応差 | 改善 / 同値 / 悪化 seed |
| --- | ---: | ---: | ---: | --- |
| JVS | 1.001% | 0.926% | −0.075 pp | 3 / 0 / 0 |
| Common Voice | 2.556% | 2.400% | −0.156 pp | 2 / 0 / 1 |
| JTube | 0.929% | 0.938% | ＋0.010 pp | 0 / 2 / 1 |
| 等コーパス平均 | 1.495% | 1.421% | −0.074 pp | 3 / 0 / 0 |

平均EERは約4.9%の相対低下。ただし平均差の対応付き話者bootstrap 95%区間は
**[−0.152, ＋0.017] pp**で0を含む。コーパス別の区間もすべて0を含む。
この区間は選択集合と既存モデルを固定した条件付きの値で、音素探索や学習の変動を含まない。

全入力FAR/FRRの等コーパス平均は0.870→0.875% / 28.457→28.030%。
Common VoiceではFRRが41.370→40.222%に下がる一方、FARは0.852→0.895%へ上がった。
EER低下を、FARを維持した運用性能の改善と同一視しない。

## 確認用話者では改善が残らなかった

探索側の平均EERは1.333→1.284%。選択を固定した後に評価した確認側は
**1.809→1.811%**で、平均改善を確認できなかった。
確認側ではJVSとJTubeが改善した一方、Common Voiceは3.494→3.748%へ悪化した。
全validationでは1.482→1.551%だった。確認側・全validation・testの結果で集合を選び直していない。

探索/確認ではquery話者とclaimed speakerの両方を分離している。
全validationには探索側と確認側をまたぐ他人照合もあるため、全validation EERは両側EERの平均にはならない。
確認用話者も元のTransformer checkpoint選択には使われており、完全に独立したholdoutではない。
testも既観測の話者集合なので、今回のtest改善だけで汎化を確定しない。

## 音素の利用可能性にも差がある

「36音素」は候補inventoryを表し、各発話が36種類すべてを使うわけではない。
登録側全話者にそろい、照合発話にもある音素だけが元から利用される。
通常文の採点可能な照合発話における`ch`の利用率は次のとおり。3モデルでmaskは同一だった。

| コーパス | validation | test |
| --- | ---: | ---: |
| JVS | 48.98% | 48.98% |
| Common Voice | 0.00% | 27.71% |
| JTube | 25.28% | 0.00% |

Common Voiceのvalidationでは`ch`除外の効果を測れておらず、JTubeのtestでは`ch`除外はスコアを変えない。
そのため、各コーパスで同じ音素介入を同じ程度に検証できたわけではない。
また、`dy`は今回の通常文採点対象では全6集合を通じて利用されなかった。
同値の除外を採用しない探索規則により残っており、保持されたことを有効性の証拠としない。

5母音はすべて選択集合に残った。ただし、今回のモデル・探索経路の結果であり、
5母音すべてが常に必要という証明ではない。

## 完了確認

- 6単体テスト、Ruff check / format checkを通過。
- 元モデルのスコアを差0で再現。全validation/testの両集合で、projection cacheと通常forwardの差も0。
- 保存済み探索スコア4,372,620件からEERを別計算し、140候補の探索手順と選択集合を再現。
- 評価スコア525,420件、閾値・採点率・FAR/FRR・EERを検算。指標差の最大は浮動小数点誤差の5.56e-17未満。
- 最後の完了通知だけで失敗したv1を保存し、通知を修正したv2で全計算を再実行。
  選定規則・推論・評価は不変。439配列ファイル、4,911,040浮動小数点値が完全一致した。
- 既存モデル・入力のhashは不変。再学習や標準照合設定の変更はしていない。

今回得られたのは、固定モデルでの小さな改善候補である。
34音素を確定的な最適集合として扱わず、追加検証する場合の候補として保持する。
