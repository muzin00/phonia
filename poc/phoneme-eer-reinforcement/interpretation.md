# EER報酬の強化学習2案の結果

実測EERを報酬にしたREINFORCEは、音素の重み付け・音素集合の選択の両方で動作した。
今回の主結果では重み付けに小さな改善傾向があるが、改善は確立していない。
音素選択では追加前が全seedで選ばれた。標準モデルは変更しない。

## 主結果と固定終点

通常文JVS/CV/JTubeを等重みで平均し、さらに3音響seedを平均したtest EER。
selectedはvalidationで選んだモデル、finalは事前固定した500更新時点である。

| 条件 | validation選定モデル | 固定500更新 |
| --- | ---: | ---: |
| 追加前 | 1.495% | — |
| BCE対照 | 1.495% | 1.578% |
| 重み付けRL | 1.474% | 1.423% |
| 音素選択RL | 1.495% | 1.684% |

重み付けRLは3seedのうち2つで400更新、1つで追加0が選ばれた。
選定モデルのtest差は元モデル／BCE選定に対して−0.021ポイントで、2seed改善・1seed同値。
対応付き話者bootstrapの95%区間は[−0.049, ＋0.056]ポイントで0を含む。
CVは2.556→2.461%だが、JVSは1.001→1.033%に上がり、JTubeは0.929%で同値だった。
一律の改善とは言えない。

重み付けRLの固定終点1.423%は、元モデルより−0.072ポイント、3/3seed改善。
ただし差の95%区間は[−0.136, ＋0.046]ポイントで0を含む。
同じ500更新のBCE対照より−0.155ポイント、3/3seed改善だが、その区間も[−0.370, ＋0.127]ポイント。
validationでは500更新を選んでいないため、testで良かった終点を選定結果へ差し替えない。

音素選択RLの選定モデル1.495%は、3seedすべて追加0を選んだ結果である。
実際に更新した固定終点は1.684%で、元モデルより3/3seed悪化した。
差は＋0.189ポイント、95%区間[＋0.029, ＋0.390]ポイントだった。
BCE最終との比較では＋0.106ポイント、1seed改善・2seed悪化である。
今回の設定では、音素選択の追加学習を採用する根拠は得られなかった。

## 学習自体は成立したか

BCE対照、重み付け、音素選択を各3音響seed・500更新、合計9学習した。
両RL条件ではBCEもsoft-EERも使わず、学習batchの実測EERから方策勾配を作った。
元の音響encoderと音素選択用の照合scorerは更新していない。

- 重み付けは正規分布から音素logitを抽選。探索幅は学習入力だけで校正し、seed順に6.792／4.454／5.764。
- 音素選択は空集合を除いたBernoulli分布。選んだ集合で凍結Transformerのattentionを再計算した。
- 各batch・各コーパスで4rolloutを比較し、他の3rolloutの報酬平均をbaselineにした。
- 全学習を通じた非ゼロadvantage率は重み付け45.7%、音素選択86.1%。実データの事前検査でも非ゼロ勾配を確認した。
- 学習中の平均利用可能音素数は16.60。音素選択の抽選集合は平均8.53音素だった。

これらは報酬による更新が行われたことを示す。平均8.53音素は探索中の値であり、
決定的推論で半分の音素だけ使えば精度が上がるという結果ではない。
報酬は抽選した行動に対するbatch EER、評価は決定的な行動に対する全コーパスEERである。
両者は一致せず、学習batchも更新ごとに変わるので、報酬平均の時系列だけで汎化性能を判断しない。

## 本人拒否・他人受入と採点率

validation FAR1%で固定した閾値によるtestの平均は、追加前→重み付け選定で
本人拒否28.457→28.421%、他人受入0.870→0.876%だった。
差は小さく、test FARを同一に揃えた比較でもない。
音素選択の固定終点は本人拒否30.591%となり、追加前より高かった。

採点率は全条件共通でJVS98.000%、CV64.556%、JTube59.833%。
音素選択で難しい試行を採点対象から除くことはせず、元の5母音条件と採点位置を維持した。
EERは採点可能分の指標であり、採点不能による本人拒否を解消する実験ではない。

## 検証と解釈の範囲

- 分布の正規化、厳密なKL、score-function勾配、実測EER、欠損mask、元推論との一致、3条件の完全再開を含む8テストが通過。
- 9学習の更新数、同一ペア列、初期スコア、凍結scorer、checkpoint選定を監査。
- 全モデルと63個のvalidation閾値を固定してからtestを推論。
- 保存スコア1,838,970個の直接forwardとの差は最大0。
- EER/FAR/FRRの独立再計算との差は最大5.56e-17。固定した入力・コード362ファイルの不変性も確認。
- 対応付きquery/claimed話者bootstrapを1,000回実施。固定モデルを条件とする区間で、学習・選定の変動は含まない。

全testは既観測で、3音響seed・1方策seed・単一設定の実験である。
前回のsoft-EER実験とはbatch、更新数、dropout条件が違うため、今回の1.423%と前回の1.489%だけを比較して
「強化学習がsoft-EERより優れる」とは結論しない。対照は今回同時に実行したBCE条件である。
今回の結果は重み付けRLを追加検証する候補にはなるが、運用モデルを置き換える証拠としては不足する。
