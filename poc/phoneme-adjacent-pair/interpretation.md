# 隣接音素の単純結合で分かったこと

**10種類の子音→母音をすべて連続区間として扱う方式は、分離方式の平均EERを改善しなかった。**
同じ音声範囲・総時間、同じ学習token列、同じ初期値とモデル規模で3 seedずつ学習した。
test平均EERは分離2.548%から結合2.837%へ上がり、3 seedすべてで悪化した。
ただし、ペア別では`t+a`が3コーパス×3 seedの全9条件で改善しており、結合効果は一様ではない。

## 全ペアの統合結果

60,000更新の固定最終モデルを使用。3 seed平均、平均行はコーパスを等重みにした。

| test EER | 分離 | 結合 | 結合−分離 |
| --- | ---: | ---: | ---: |
| JVS | 1.674% | 1.885% | +0.211ポイント |
| Common Voice | 3.658% | 3.794% | +0.135ポイント |
| JTube | 2.311% | 2.833% | +0.522ポイント |
| 平均 | 2.548% | 2.837% | +0.289ポイント |

平均差の対応付き話者bootstrap 95%区間は[-0.058, +0.528]ポイントで0を含む。
普遍的な悪化が確定したとは言えないが、今回の単純結合方式を採用する根拠は得られなかった。
平均のseed別差は+0.251 / +0.263 / +0.354ポイント。
validationも平均2.423→2.778%で、3コーパスの平均値がすべて悪化した。

固定閾値のtest平均FARは1.159→1.286%、全入力FRRは29.310→29.383%。
全体として運用指標の改善もない。
JVS別テキストの副評価では1.567→1.385%と全3 seedで改善したが、主結果と分けて扱う。

## ペアごとには異なる傾向がある

同じペアの行内では分離/結合の対象発話と音声量が一致する。

| `t+a`単独のtest EER | 分離 | 結合 | 改善seed |
| --- | ---: | ---: | --- |
| JVS | 8.757% | 7.515% | 3 / 3 |
| Common Voice | 8.177% | 7.430% | 3 / 3 |
| JTube | 6.767% | 6.246% | 3 / 3 |

`k+a`はJVSで7.508→6.046%、JTubeで4.745→4.444%へ下がった一方、Common Voiceは6.440→6.763%へ上がった。
`n+a`・`n+i`・`n+o`は、いずれも3コーパスそれぞれのseed平均で結合側が悪化した。
JVSでは10種類中7種類のペア別EERが改善したのに、全種類の等重み統合EERは悪化した。
ペア単独での改善が、そのまま統合後の改善になるとは限らない。
スコア分布や誤りの重なりが関係する可能性はあるが、原因は今回測定していない。

これらは事前固定した全10種類を報告した副評価の中での観察であり、種類ごとの多重比較補正や独立確認はしていない。
ペアごとに対象発話が違うため、絶対EERの順位をペア固有の優劣と扱わない。
今回のtest結果を使って結合ペアを選び直したり、混合モデルのtest EERを追加探索したりはしていない。

## 採点率と利用可能性

分離/結合の採点率は同一で、testはJVS 97.867%、Common Voice 63.222%、JTube 58.833%。
元の5母音条件に加えて対象ペアが必要なため、元システムの98.000% / 64.556% / 59.833%より僅かに低い。
未採点発話を削除せず、全入力FRRに拒否として含めた。EERは採点可能な照合について計算した。

validationでは全10種類が全登録話者に揃ったが、JTube testでは`r+u`が18/20話者、`t+e`・`t+o`が各19/20話者にしかなかった。
claimによって利用音素を変えない規則に従い、両条件ともJTube testでこの3種類を使わなかった。
ペア別表の0件は「全登録話者に揃わず未採点」という意味で、そのペアがtest音声に全く存在しないという意味ではない。

## 今回切り分けた範囲

対象は`de, ka, na, ni, no, ru, shi, ta, te, to`。119候補から、train/validationの出現数・話者充足だけで10種類を選んだ。
音素境界が厳密に接し、各音素30ms以上・合計250ms以下の既存QC合格区間に限定した。
元WAVの同じPCM frameを使い、crop、延長、別区間の接ぎ合わせは行っていない。

分離側はCとVそれぞれの平均・標準偏差を共有MLPへ通し、正規化embeddingを等重み平均して再正規化した。
結合側は同じ連続C+V区間の平均・標準偏差をMLPへ入力した。
モデルはいずれも65,920 parameters。乱数shapeとdropout maskの扱いも条件間で揃えた。
この差には前処理・特徴抽出・集約の違いが含まれ、時間順序や調音遷移だけの効果を測ったわけではない。

今回はペアだけの等重み統合で、以前の全36音素Transformerとは入力・学習・統合方式が異なる。
以前の平均EER 1.495%と今回の2.548%を、そのまま音素結合の効果として比較してはいけない。
今回の結合による対応差は2.548→2.837%である。
全testは既観測。CIは固定モデル・固定ペア集合に条件付きで、学習やペア選択の不確実性は含まない。

## 完了確認

- 2条件×3 seedを各60,000更新まで完走。全モデルとvalidation閾値を固定してからtestの抽出・推論を行った。
- 元の490学習ラベル中、対象ペアを持つ489ラベルを両条件で共通に使用。学習区間は288,266組。
- 8単体テスト、Ruff check / format checkを通過。同一入力時の出力・勾配・乱数一致、未使用branchの勾配0、再開時のmodel/head/optimizer/乱数/履歴の完全一致などを検証した。
- 349,965組の境界と同じPCM範囲を監査。全分離特徴は元cacheと完全一致し、原音声からの特徴再計算probeの差も0だった。
- 520,590スコア値のEER/FAR/FRRを再集計し、最大指標差は約5.4e-17。話者・WAV hashの分離、学習ペアと初期値の一致も確認した。
- v1は全490人に対象ペアがあるという前提チェックで、学習更新前に停止。旧ソースを保存し、実数489人を記録するv2で実行した。
  再抽出した11ファイル・122,990,592特徴値はv1と完全一致し、ペア選択と区間・予算は変えていない。

今回の全種類一律結合は採用を見送る。
`t+a`などに限定した結合や時間順序を保持する表現は、別の仮説として検証する余地がある。
